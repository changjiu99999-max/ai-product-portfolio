# Chang Ke · 常可

**AI Product Manager / AI Application Product Manager**

将复杂业务问题转成可执行、可审阅的 AI 与数据产品。我的项目覆盖制造质量调查、商品采购决策、Agent 平台及专业统计分析，关注从问题定义到产品交付、验收与证据追溯的完整过程。
